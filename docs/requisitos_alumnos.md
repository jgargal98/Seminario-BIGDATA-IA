# Requisitos para el seminario «Big Data con IA»

## Equipo
- Portátil con Windows, Mac o Linux.
- 8 GB de RAM y 5 GB libres en disco.

## Cuentas
- Plan Pro de Claude.
- GitHub (gratis).
- Hugging Face (gratis, recomendable).

## Programas
- Git.
- Claude Code: la app de escritorio de Claude (pestaña Code) o el comando `claude` en la terminal.
- uv.

## Antes del seminario

```bash
git clone [URL_DEL_REPOSITORIO]
```

```bash
cd seminario-bigdata-ia
```

```bash
uv run scripts/check_setup.py
```

Tiene que terminar diciendo **«Todo listo para el seminario»**. Los comandos de instalación de cada programa están en el README.
